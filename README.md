# AdventureWorks Sales Dashboard 2021

An interactive Power BI dashboard analyzing 23,900+ sales transactions from 2021.

<img width="802" height="497" alt="AdventureWorks Dashboard 2021" src="https://github.com/user-attachments/assets/4424e716-871c-4f37-82e3-db8a3e0e1947" />

## 🔑 Key figures
- **Total revenue:** $9.32M
- **Total profit:** $3.97M
- **Profit margin:** 42.55%
- **Orders:** ~10.7K

## 💡 Insights
- Revenue was steady from January to June, then grew sharply from July, peaking in December.
- Mountain-200 bikes generate the most revenue, while low-cost accessories (water bottles, tire tubes, patch kits) sell in the highest volumes.
- Territory 9 leads revenue by a wide margin; territories 2, 3 and 5 contribute almost nothing, a clear area to investigate.

## 🛠️ Built with
Power BI Desktop · Power Query · DAX (SUMX, RELATED, DISTINCTCOUNT, DIVIDE) · Data modeling (star schema relationships)

## 📁 Data
AdventureWorks sample dataset (Sales + Product lookup tables).
